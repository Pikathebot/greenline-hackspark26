```ts
export interface NodeRunState { status: 'idle'|'active'|'done'; outcome?: NodeExitStatus
  durationMs?: number; note?: string; enteredAt?: number }
export type LogEntry      = Omit<LogEvent, 'type'>          // { t, node, level, text }
export type EvidenceEntry = Omit<EvidenceEvent, 'type'>     // { t, node, kind, text, ref? }
export type RerunTick     = Omit<RerunTickEvent, 't'|'type'|'total'>  // { n, passed, durationMs }
export type MemoryHit     = Omit<MemoryHitEvent, 't'|'type'>
export type Verdict       = Omit<VerdictEvent, 't'|'type'>
export type PatchAttempt  = Omit<PatchAttemptEvent, 't'|'type'>
export type CriticVote    = Omit<CriticVoteEvent, 't'|'type'>
export type GuardrailState = { fired: boolean; note: string; t: number }
export type Report        = Omit<ReportEvent, 't'|'type'>
export interface RunState {
  runId: string|null; caseId: string|null; mode: RunMode|null; model: string|null
  budgetPreset: BudgetPreset|null; caps: BudgetCaps|null
  nodes: Record<NodeId, NodeRunState>; activeNode: NodeId|null; path: NodeId[]
  narration: string|null; logs: LogEntry[]; evidence: EvidenceEntry[]
  rerun: { total: number; ticks: RerunTick[] } | null
  memoryHit: MemoryHit|null; verdict: Verdict|null
  patchAttempts: PatchAttempt[]; criticVotes: CriticVote[]
  guardrails: Record<RailId, GuardrailState | undefined>
  budget: { modelCalls: number; toolCalls: number; elapsedMs: number }
  report: Report|null; error: string|null; outcome: Outcome|null; lastT: number

```

`EMPTY_STATE`: every node `{ status: 'idle' }` (built from `NODE_IDS`), every rail key present
with value `undefined` (built from `RAIL_IDS`), arrays `[]`, nullable fields `null`, budget
`{0,0,0}`, `lastT: 0`. Export it **deep-frozen** (a small local `deepFreeze` helper) so any
accidental mutation throws in tests (ESM is strict mode).

## `src/state/reducer.ts`: semantics per variant

Signature: `export function reduce(state: RunState, e: GreenlineEvent): RunState` and
`export function reduceAll(events: readonly GreenlineEvent[], from: RunState = EMPTY_STATE): RunState`
(`events.reduce(reduce, from)`).

Rules for every case: never mutate `state` (spread / new arrays only). Every returned state has
`lastT = Math.max(state.lastT, e.t)`, except `run.start`, which sets `lastT = e.t`. Copy optional
fields **only when defined** (`...(e.ref !== undefined && { ref: e.ref })`) so the debug JSON
has no `undefined` keys. Strip `t`/`type` by destructuring (`const { t, type, ...rest } = e`).
End the `switch (e.type)` with `default: { const _x: never = e; return state }` for exhaustiveness.
No guards for events before `run.start` or after `done`: the reducer applies what it is given;
the stream/runStore (A3) owns reset-on-reconnect.

| Variant | Effect on `RunState` |
|---|---|
| `run.start` | Return `{ ...EMPTY_STATE, runId, caseId, mode, model, budgetPreset, caps, lastT: e.t }` (fresh object; `EMPTY_STATE` is never mutated). **Resets** everything from a previous run. |
| `node.enter` | `nodes[node] = { status: 'active', enteredAt: e.t }` (a re-entered node, e.g. patcher on attempt 2, loses its previous outcome/duration/note). `activeNode = node`. `path = [...path, node]`. If a *different* node was still active (invariant 3 violated), close it first exactly as `node.exit` with `status: 'fail'` and `durationMs = e.t - enteredAt` (defensive; still at most one active). |
| `node.exit` | `nodes[node] = { status: 'done', outcome: e.status, durationMs: e.durationMs, enteredAt: prev.enteredAt, note?: e.note }`. `activeNode = activeNode === node ? null : activeNode`. `path` unchanged (exit without enter, e.g. defensive skip, still marks the node done). |
| `log` | `logs = [...logs, { t, node, level, text }]`. If `level === 'info'`, `narration = text`; `warn`/`error` leave narration unchanged. |
| `evidence` | `evidence = [...evidence, { t, node, kind, text, ref? }]`. |
| `rerun.tick` | `rerun = { total: e.total, ticks: [...(rerun?.ticks ?? []), { n, passed, durationMs }] }`. |
| `memory.hit` | `memoryHit = { caseRef, similarity, summary }`. |
| `verdict` | `verdict = { cls, confidence, rationale }` (latest wins; invariant 4 says at most one). |
| `patch.attempt` | `patchAttempts = [...patchAttempts, { n, file, diff, source, result }]`. |
| `critic.vote` | `criticVotes = [...criticVotes, { n, samples, deterministic, approved }]` (copy arrays). |
| `budget` | `budget = { modelCalls, toolCalls, elapsedMs }` (replace, not add). |
| `guardrail` | `guardrails = { ...guardrails, [rail]: { fired, note, t: e.t } }` (latest per rail). |
| `report` | `report = { kind, title, body, prUrl?, dryRun? }`. |
| `error` | `error = e.message`. If `activeNode !== null`, close that node as `status: 'done', outcome: 'fail', durationMs: e.t - enteredAt` and set `activeNode = null`. (B's run manager emits `error` without a `node.exit`, see `backend/greenline/graph/run.py`; without this the graph would show a node active forever.) |
| `done` | `outcome = e.outcome`. If `activeNode !== null`, close it as `fail` the same way; `activeNode = null`. |

Display-only facts (elapsed ticker, wall clock) never enter `RunState`.

## `src/contract/invariants.ts`

`export function checkInvariants(events: readonly GreenlineEvent[]): string[]`: returns one
human-readable message per violation, each prefixed with its id (`"I1: ..."` … `"I6: ..."`),
empty array when valid. I7 is backend-only (not checkable from a stream).

| Id | Check |
|---|---|
| I1 | non-empty; `events[0]` is `run.start` with `t === 0`; last event is `done`; exactly one `done` |
| I2 | `t` non-decreasing across the list |
| I3 | walking the list, a `node.enter` while another node is active is a violation; a `node.exit` for a node that isn't the active one is a violation (skips included: the backend always enters before a skip exit, `05` §Reproducer) |
| I4 | at most one `verdict` |
| I5 | `rerun.tick` events: `n` sequence is exactly `1, 2, …` in order, all with the same `total`, and `n ≤ total` |
| I6 | if `done.outcome` ∈ {`reported`,`escalated`,`budget_exhausted`}, a `report` appears before `done` |

Note: an `error`-terminated run legitimately leaves a node active (no exit) → I3 does **not**
require every enter to be closed before `done`.

**Semantics**
- `log` with level `warn` after an `info`: logs grows, narration unchanged.
- `node.exit` without `note` leaves no `note` key (`'note' in s.nodes.x` is false).
- `report` without `prUrl`/`dryRun` leaves no such keys.
- guardrail same rail twice → latest wins.
- `run.start` reset: `reduceAll(HERO_0142)` then `reduce(_, run.start of WARM)` equals
  `{...EMPTY_STATE, <WARM run.start fields>}`.
- `PATCH_LOOP_0137`: path contains `patcher, critic, patcher, critic` in order; patchAttempts
  results `['red','green']`; criticVotes approved `[false,true]`; `nodes.patcher.outcome === 'ok'`
  after the second exit.
- `WARM_0144`: `nodes.reproducer` = done/skip with note; memoryHit set; rerun null.
- `ERROR_RUN`: final `nodes.triage` = done/fail with `durationMs = error.t - enteredAt`;
  activeNode null; error message set; outcome `error`; report null; verdict null.
- defensive: `node.enter` B while A active → A done/fail, B active, exactly one active.

**Purity**
- For every sequence, `reduceAll` over a deep-frozen start never throws (freeze each
  intermediate state before the next step) and returns deep-equal output when run twice.
- The input state object is unchanged (`toEqual` a `structuredClone` taken before).

**Per invariant (stepwise over every sequence in `ALL_SEQUENCES`)**
- I1: after step 0 `runId` is set and `outcome` null; `outcome` becomes non-null only at the final
  `done`; final `lastT === last event t`.
- I2: `lastT` non-decreasing after every step.
- I3: after every step, the number of nodes with `status === 'active'` is ≤ 1 and equals
  `activeNode === null ? 0 : 1`; after the final `done`, it is 0.
- I4: HERO/WARM/PATCH_LOOP have a verdict; TIGHT and ERROR end with `verdict === null` and
  outcome `budget_exhausted` / `error` (the UI's "no verdict reached" input).
- I5: HERO final `rerun.ticks.map(t => t.n)` is `[1..10]`, `total` 10, passes 7, fails 3.
- I6: for HERO, WARM, PATCH_LOOP, TIGHT the state just before `done` already has `report !== null`;
  ERROR ends with `report === null` (allowed).
- I7: (static) `src/state/` never imports `contract/case` (checked by the grep below).
