# A10: polish (declutter, scaling, lost-stream, light theme)

Built 8 Oct 2026. Build-plan row: polish against every state frame; light theme on hidden key `L`;
125% scaling; reduced motion; no layout shift during a run.

## Shipped
- **Declutter** (`df10589`, `8b5a135`, `79160d8`): verdict rationale clamped to 2 lines with more/less,
  idle guardrails as names only, one-line artifact placeholder, legend only once a run starts, unused
  graph arcs hidden when a run ends, 2-line case cards, evidence rows clamp to 3 lines, Tight hint as
  a tooltip, a finished run is cleared when another case is selected (`src/app/runReset.ts`).
- **Lost stream** (`41bcd00`): `verdictView` says "No verdict reached / Lost the run stream." when
  `status === 'error'`, instead of "Gathering evidence…".
- **125% scaling** (`41bcd00`): compact-size rules in `screen.css` (meters 120px, node names 16px,
  narration clamped to 2 lines at 20px). 125% of 1080p is about 1536×864 CSS px, which is the compact
  layout already checked at 1528×784.
- **Light theme:** `uiStore.theme` (`'dark'` default, not persisted) + `toggleTheme`, `L` key in
  `src/app/useKeyboard.ts`, and a subscriber in `src/app/bootstrap.ts` that sets
  `document.documentElement.dataset.theme`. The light palette already existed in `tokens.css`.
  No visible toggle, by design.

## Findings
- **Banner:** it is `position:absolute`, so it overlays the case bar and takes no space. It does not
  shift the layout (an earlier note saying otherwise was wrong).
- **No layout shift:** measured with `getBoundingClientRect` during a recorded and a live #0144 run:
  the top bar, graph and narration/summary slot never moved; only the evidence feed changes height
  (453px → 397px) when the memory callout appears.
- **Reduced motion:** already covered by `tokens.css` (global) and `screen.css` (`.live-dot`,
  `.pulse`, `.barrier`). No change needed.
- **Light theme checked on:** idle, finished escalated (red barrier, guardrails), finished reported
  (PR diff, critic, guardrails) and the scoreboard overlay. No token fixes were needed.
- **Dev-server gotcha:** after several quick edits, Vite served a stale copy of
  `useKeyboard.ts` (the `L` case was missing). `touch` on the changed files fixed it. The production
  build was never affected.
