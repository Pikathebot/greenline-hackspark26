### `format.ts`
- `fmtClock(ms)` → `MM:SS` (floor seconds): 6200 → `00:06`.
- `fmtClockTenths(ms)` → `MM:SS.t` (floor to tenth): 33950 → `00:33.9`; 34000 → `00:34.0`; 300 → `00:00.3`.
- `fmtSeconds(ms)` → one decimal + `s`: 4120 → `4.1s`.
- `fmtMeterSeconds(ms)` → `${Math.floor(ms/1000)}s` (time meter value/cap): 180000 → `180s`.
- `formatModel(name)` → `name[0].toUpperCase()+rest`, then `(\d)b\b` → `$1B`: `qwen3-8b` → `Qwen3-8B` (chip text is `${formatModel(name)} · local`).

### `graph.ts`
```ts
export interface NodeView { id: NodeId; step: string; name: string; role: string
  status: 'idle'|'active'|'ok'|'skip'|'fail'; detail: string; title: string  // title = tooltip (full note)
  connColor: string | null   // CSS colour of the bar to the NEXT node; null for the last node
  barrier: boolean }
export function nodeViews(s: RunState): NodeView[]   // 7 items, NODE_IDS order
```
Status: `idle`→`idle`; `active`→`active`; `done` → `outcome` (`ok|skip|fail`).
**Critic override (derived from events, not hardcoded):** if `criticVotes` is non-empty and the *latest* vote has `approved === false`, the critic node's status is `fail` (design frame 07: red, "rejected #1") regardless of its `node.exit` status; a later approved vote restores `ok`.
**Detail** (reference line 781-782 + frames):
- idle → `s.outcome !== null ? 'not reached' : 'waiting'`
- active → reproducer with `s.rerun`: `rerun ${ticks.length} / ${total}`; patcher: `attempt ${count of 'patcher' in s.path} / ${MAX_PATCH_ATTEMPTS}`; otherwise `running…`
- ok → `fmtSeconds(durationMs)`
- skip → `'skipped'` + (`s.memoryHit && id==='reproducer'` ? `' · memory'` : `''`)
- fail → critic override: `rejected #${latestVote.n}`; else `node.note ?? 'failed'`
- `title`: `node.note ?? ''`.
**Connector colour** for node i < 6 with `next = nodes[i+1]`: default `var(--border-strong)`; if neither is idle → `next.status==='active' ? 'var(--info)' : 'var(--brand)'`; **if i===3 and the barrier shows → `var(--danger)`**. `barrier` (on node index 3, the analyst) = `s.guardrails.protected_file?.fired === true`.

```ts
export interface ArcView { from: number; span: number; on: boolean; tone: ToneName; label: string; show: boolean }
export function arcViews(s: RunState): { loop: ArcView; bypass: ArcView; esc: ArcView }
```

### `useElapsed.ts`
```ts
export function interpolateElapsed(lastT: number, lastArrivalMs: number, nowMs: number): number  // lastT + max(0, nowMs - lastArrivalMs)
export function useElapsedMs(): number
```
Hook: reads `useRunStore` `status` and `state.lastT`; keeps `arrival = performance.now()` in a ref updated whenever `lastT` changes; while `status==='streaming'` a 250 ms `setInterval` re-renders with `interpolateElapsed(lastT, arrival, performance.now())`; when `done`/`error` returns `state.lastT` (authoritative `done.t`); when no run returns 0. (Interpolating from the latest event `t` makes a mid-run re-attach/refresh show the right time.) Top bar shows `fmtClock(ms)` while running and `fmtClockTenths(ms)` once done; `--:--` when the backend is unreachable.
