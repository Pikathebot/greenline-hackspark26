### `patch.ts`
```ts
export interface DiffLine { kind: 'hunk' | 'add' | 'del' | 'ctx'; text: string }
export function parseDiff(diff: string): DiffLine[]
```
Split on `\n` (drop one trailing empty segment). **Skip** header lines: those starting with `diff `, `index `, `--- `, `+++ ` (the file name is shown in the block header instead). Then: starts with `@@` → `hunk` (text as is); starts with `+` → `add`, text as is (the `+` stays, matching the reference `'+' + text`); starts with `-` → `del`; starts with `\` (e.g. `\ No newline at end of file`) → skip; anything else → `ctx` (if it starts with a single space keep it as is, else prefix one space). Empty input → `[]`.
Reference styling (lines 887-892) to apply in the component: add `background:var(--brand-tint);color:var(--brand-ink)`, del `background:var(--danger-tint);color:var(--danger)`, hunk `color:var(--info)`, ctx `color:var(--muted)`; class `dl`.

```ts
export interface CheckView { name: string; passed: boolean; detail: string }
export interface VoteView { n: number; approvals: number; total: number; samples: ('approve'|'reject')[]
  approved: boolean; text: string; checks: CheckView[] }
export function voteView(s: RunState, n: number): VoteView | null     // the critic vote for attempt n (latest one if several), else null
```
`text`: samples non-empty → `approved ${approvals} / ${total}` if `approved` else `rejected ${rejections} / ${total}`; samples empty → `approved` is false → `rejected by deterministic checks`; samples empty and approved true → `approved by deterministic checks`.

```ts
export interface AttemptView {
  n: number; file: string; source: 'model'|'tool'
  state: 'green' | 'red' | 'vetoed' | 'running'
  note: string                    // muted text after the chip (below)
  diff: DiffLine[]
  vote: VoteView | null
  running: boolean                // true only for the in-progress card
  body: string                    // running card text
}
export function attemptViews(s: RunState): { attempts: AttemptView[]; acceptedN: number | null }
```
- One `AttemptView` per `s.patchAttempts[i]` (state = its `result`), `vote = voteView(s, n)`.
- `note`: `vetoed` → `blocked by a guardrail`; `red` or any attempt whose `vote?.approved === false` → `rejected by Critic`; `green` with an approving vote → `approved by Critic`; `green` with no vote yet → `awaiting Critic`.
- **Running card** appended when `s.outcome === null && s.activeNode === 'patcher' && patcherEntries > s.patchAttempts.length` (`patcherEntries` = count of `'patcher'` in `s.path`): `n = patcherEntries`, `state:'running'`, `running:true`, `file:''`, `diff:[]`, `vote:null`, `body = s.narration ?? 'Running the patched tests in the sandbox.'`, `note:\`${n} / ${MAX_PATCH_ATTEMPTS}\``.
- `acceptedN` = `s.report?.kind === 'pr'` ? `n` of the **last** attempt with `result==='green'` : `null`.

### `memory.ts`
```ts
export interface BarView { label: string; a: string; b: string; aPx: number; bPx: number }
export interface MemoryView { ref: string; sim: string; text: string; bars: BarView[] | null }
export function memoryView(p: { s: RunState; cases: CaseSummary[] }): MemoryView | null
```
`null` when `s.memoryHit === null`. Else `ref = '#' + caseRef`, `sim = similarity.toFixed(2)`, `text = summary`. `bars` is `null` unless `s.outcome !== null` **and** the case `caseRef` exists in `cases` with `lastRun !== null`; then three bars, in this order, `a` = this run, `b` = the recalled case's last live run:
1. `Time`: `a = (s.lastT/1000).toFixed(1) + ' s'`, `b = (lastRun.durationMs/1000).toFixed(1) + ' s'`, values in seconds for px.
2. `Sandbox runs`: `s.budget.toolCalls` vs `lastRun.toolCalls`.
3. `Model calls`: `s.budget.modelCalls` vs `lastRun.modelCalls`.
Bar widths (reference 831): `px = Math.max(4, Math.round(v / Math.max(a, b, 1e-9) * 150))` where `max = Math.max(a,b) || 1`. Reference colours: this-run bar `var(--brand)`, recalled bar `var(--muted)`.
