# A8: ScoreboardOverlay

Built 8 Oct 2026. Acceptance (docs/10-BUILD-PLAN.md): renders the real `/api/scoreboard`.
Spec: docs/08-FRONTEND-SPEC.md. Design: `frontend/design/state-12-scoreboard.png`.

## What it does
Opens from the TopBar Scoreboard button or the `S` key, closes on Esc, the Close button or a click
on the backdrop. It fetches `GET /api/scoreboard` each time it opens and keeps the last data if a
refresh fails.

- **Chip:** `from N live runs`, plus `small sample` under 30 runs (doc 13: say it on screen).
- **Six tiles:** triage accuracy, patch success, escalation rate, median to verdict, P95 duration,
  warm vs cold. A `null` metric shows `–` and the subtitle `not measured`. Nothing is invented.
- **Matrix:** full 5×5 in the order `FAILURE_CLASSES`; the sparse API matrix is filled with zeros.
  Diagonal cells are brand-coloured, off-diagonal cells warn-coloured, zeros muted.
- **Per case:** case, runs, last outcome pill, median duration.
- **Footnote:** lists `notMeasured` (false-PR rate, human baseline).
- **Offline:** one line, "Scoreboard unavailable: backend unreachable.", and a working Close.

## Verified
Tests, lint and build pass. In Chrome against B's backend the tiles, matrix and per-case table
matched `curl /api/scoreboard`, Esc closed the overlay, and a stubbed failing fetch showed the
offline line. No runs were started.
